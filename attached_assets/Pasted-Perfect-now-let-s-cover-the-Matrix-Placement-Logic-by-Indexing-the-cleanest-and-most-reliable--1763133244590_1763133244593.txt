Level	Slots	Index Range	Parent Formula
0	1	0	root (no parent)
1	2	1–2	parent = floor((i-1)/2)
2	4	3–6	parent = floor((i-1)/2)

Total slots = 63

📘 This is basically a binary heap layout, which maps a full binary tree into a linear array.

🧮 3️⃣ PLACEMENT ALGORITHM (By Index)

Algorithm to place new users automatically in the first open slot (index-based):

def place_user_in_matrix(matrix_id, user_id):
    matrix = db.get_matrix(matrix_id)
    next_index = matrix["filled_slots"]  # next open slot in sequence (0-based)

    if next_index >= matrix["total_slots"]:
        # matrix full — mark inactive and trigger re-entry or next matrix
        db.update_matrix(matrix_id, {"is_full": True})
        trigger_new_matrix(matrix["root_user"])
        return

    # Calculate parent index (except for root)
    parent_index = None
    if next_index > 0:
        parent_index = (next_index - 1) // 2

    # Determine level from index
    level = int(math.log2(next_index + 1))

    # Create slot entry
    db.insert("matrix_slots", {
        "matrix_id": matrix_id,
        "slot_index": next_index,
        "user_id": user_id,
        "parent_index": parent_index,
        "level": level,
    })

    # Increment filled slots count
    db.update_matrix(matrix_id, {"filled_slots": next_index + 1})

    print(f"User {user_id} placed at index {next_index} (level {level}) under parent {parent_index}")


✅ No recursion — everything derived from simple arithmetic.

⚖️ 4️⃣ PARENT–CHILD RELATIONSHIP BY INDEX

Given index i:

Parent index = (i - 1) // 2

Left child index = 2*i + 1

Right child index = 2*i + 2

Example:

Index	Parent	Left Child	Right Child	Level
0	—	1	2	0
1	0	3	4	1
2	0	5	6	1
3	1	7	8	2
4	1	9	10	2

So if you store all slots in an array, you can compute relationships instantly.

🧠 5️⃣ GLOBAL AUTO-FILL FLOW (Continuous)

When matrix full (63 slots):

Mark it inactive (is_full = true)

Root user triggers auto re-entry (starts a new matrix)

Next new user continues from global queue in next available matrix

Global function example:

def get_next_available_matrix():
    m = db.query("SELECT * FROM matrices WHERE filled_slots < total_slots ORDER BY id ASC LIMIT 1")
    if not m:
        # create new matrix under admin or global root
        return create_new_matrix(global_root)
    return m


Then in activation:

matrix = get_next_available_matrix()
place_user_in_matrix(matrix["id"], user_id)

💰 7️⃣ INCOME DISTRIBUTION BY LEVEL (optional)

If you also track level-based income, you can pre-compute uplines using indexing math:

def get_uplines(slot_index):
    uplines = []
    while slot_index > 0:
        slot_index = (slot_index - 1) // 2
        uplines.append(slot_index)
    return uplines


Example:
User at slot 25 → uplines = [12, 5, 2, 0]
→ pays 4 uplines (levels 1–4)

🧰 10️⃣ SQL Example (for reference)
CREATE TABLE matrices (
  id INT AUTO_INCREMENT PRIMARY KEY,
  root_user VARCHAR(50),
  total_slots INT DEFAULT 63,
  filled_slots INT DEFAULT 0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE matrix_slots (
  id INT AUTO_INCREMENT PRIMARY KEY,
  matrix_id INT,
  slot_index INT,
  user_id VARCHAR(50),
  parent_index INT,
  level INT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (matrix_id) REFERENCES matrices(id)
);
